# AI Interview Simulator — النسخة الداخلية

نظام داخلي مبني على Streamlit لتوليد مقابلات وظيفية كاملة باستخدام الذكاء الاصطناعي. 
يوفر أسئلة تقنية وسلوكية وشخصية مبنية على السيرة الذاتية، مع تقييم فوري لجودة الإجابات.

---

## المميزات
- توليد مقابلة كاملة خلال ثوانٍ
- أسئلة تقنية دقيقة حسب مجال المرشح
- أسئلة سلوكية مبنية على الخبرات
- تقييم فوري لكل إجابة
- تقرير شامل للمرشح
- واجهة عربية سريعة وواضحة

---

## طريقة العمل
1. رفع السيرة الذاتية 
2. توليد أسئلة المقابلة تلقائيًا 
3. الإجابة داخل النظام 
4. تحليل الإجابات وتقييمها 
5. عرض تقرير نهائي للمرشح

---

## التقنية المستخدمة
- Python 
- Streamlit 
- Groq API 
- نماذج لغوية متقدمة
